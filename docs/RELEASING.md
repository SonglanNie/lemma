# Releasing Lemma

1. **Version.** Raise `CFBundleShortVersionString` and `CFBundleVersion` in `scripts/package-app.py`, add the release to `CHANGELOG.md` and to **What's New** (`ReleaseNotesEditor` in `Sources/Lemma/Workbench/SpecialEditors.swift`).
2. **Check.** `swift test` passes; open the app in light and dark, both interface styles; CPU at rest stays near zero (`ps -o time= -p <pid>` twice, ten seconds apart).
3. **Build.** `scripts/build-app.sh --universal` (Apple silicon and Intel).
   - With a paid Apple Developer membership: `LEMMA_SIGN_IDENTITY="Developer ID Application: <name> (<team>)" scripts/build-app.sh --universal`, which signs with the hardened runtime and a timestamp.
   - Until then: `LEMMA_SIGN_IDENTITY="Lemma Release Signing" scripts/build-app.sh --universal`, the maintainer's self-signed certificate (trusted for code signing in their keychain; a backup is `~/.config/lemma-release/lemma-signing.p12`, its password in the keychain). Every release signed with it keeps one identity, so macOS keeps the Keychain and folder permissions it gave the previous version.
4. **Package.** `scripts/make-dmg.sh` writes `build/Lemma-<version>.dmg`, a copy named `build/Lemma.dmg` (the README's download link, `releases/latest/download/Lemma.dmg`), and prints the SHA-256. Without a Developer ID it adds a note on opening an app macOS cannot verify.
   - With a Developer ID: `scripts/notarize.sh build/Lemma-<version>.dmg` (once: `xcrun notarytool store-credentials lemma-notary …`).
5. **Appcast.** `scripts/make-appcast.sh` writes `build/appcast.xml`: the update Lemma's Sparkle offers to installed copies, signed with the project's EdDSA key, with this version's CHANGELOG section as its notes. The private key comes from `SPARKLE_KEY_FILE` (by default `~/.config/lemma-release/sparkle-ed25519.key`; it is also in the maintainer's login keychain under the account `lemma`, see Sparkle's `generate_keys`). Keep a copy of it somewhere safe: without it, installed copies cannot be updated any more.
6. **Publish.** `gh release create v<version> build/Lemma-<version>.dmg build/Lemma.dmg build/appcast.xml --title "Lemma <version>" --notes-file <notes>`. Installed copies read `releases/latest/download/appcast.xml`; copies without Sparkle (3.0) read the latest release's tag (`v3.0.1` → 3.0.1) and point to its page.
7. **Homebrew.** Update `version` and `sha256` in `packaging/homebrew/lemma.rb` and copy it to the tap repository (`fus3r/homebrew-lemma`, `Casks/lemma.rb`). Users install with `brew install --cask fus3r/lemma/lemma`.
