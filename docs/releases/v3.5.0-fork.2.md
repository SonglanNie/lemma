This fork's release by @SonglanNie, based on [Lemma 3.5.0](https://github.com/fus3r/lemma/releases/tag/v3.5.0). Every book is read again once after this update.

## Changes from 3.5.0-fork.1

- **Reference counts no longer cover the text.** The counts beside equations, statements and captions now sit in the page margin, level with their label. A page with no room in either margin shows no count, and hovering the label still gives it. A citation that opens a line, as in “(16c) for ∆g we have”, is no longer read as the equation's label.
- **Long proofs fold whole.** A citation wrapped to the start of a line (“…and use⏎Lemma 1:”) no longer reads as a new statement, so it neither ends the proof around it nor adds a false entry to Results. The proof of a known statement now runs to its end mark on any later page, rather than stopping after three.
- **Pages that crash macOS's text selection.** A book with such a page now gets its analysis, where before the whole book was left without one, and Lemma no longer crashes on showing the page or right-clicking it. Text can't be selected on the page and Find skips it. The right-click menu there leaves out macOS's own items, such as Copy and the zoom commands.
- **Pages whose text never finishes reading.** On a few pages macOS's text extraction never ends and took memory until the whole Mac slowed down. Analysing, indexing and searching a book now stop at 6 GB, set the page aside and carry on, so the book keeps its analysis. The page still shows and the search index reads it by OCR, but nothing on it can be selected, and Find skips it.
- **If Lemma still stops on a page.** A bad page the analysis didn't catch, or one in a book with no analysis, such as a password-protected one, can still end Lemma once. Lemma now says which page it was as it closes, and that page's text stays out of use, so the book opens safely next time.
- **Books whose page ends with a label** such as “Theorem 5.” no longer crash the analysis.
- **While a book is first analysed,** text selection, line numbers, the reading ruler and a page's references wait until the analysis has reached that page, usually a second or so, and Find fills in its results when it finishes. A book opened beside the reader is now analysed too.

## Install

Download `Lemma-3.5.0-fork.2.dmg` (or `Lemma.dmg`) below, open it and drag Lemma into Applications. It runs on macOS 15 or later, on Apple silicon and Intel. It replaces the original Lemma if you have it, and keeps your library and settings; coming from an earlier release of this fork, the windows, tabs and floating boxes you had open are not reopened the first time, since Lemma 3.5.0 saves its windows differently.

This build is not notarized by Apple, so the first time you open it macOS says it cannot verify it. Click Done, then open System Settings › Privacy & Security and click Open Anyway next to Lemma. You only do this once.
