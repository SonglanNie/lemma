This fork's release by @SonglanNie, based on [Lemma 3.6.0](https://github.com/fus3r/lemma/releases/tag/v3.6.0), which adds the PDF annotation toolbox, tighter highlights, configurable highlight shortcuts and a native workspace text editor.

## Changes from 3.5.0-fork.2

- **Open several PDFs together.** Choosing several PDFs in Finder and pressing ⌘O, or dropping them on Lemma in the Dock, now opens all of them, each in its own tab, in order. Only the first opened before.

## Install

Download `Lemma-3.6.0-fork.1.dmg` (or `Lemma.dmg`) below, open it and drag Lemma into Applications. It runs on macOS 15 or later, on Apple silicon and Intel. It replaces the original Lemma if you have it, and keeps your library and settings.

This build is not notarized by Apple, so the first time you open it macOS says it cannot verify it. Click Done, then open System Settings › Privacy & Security and click Open Anyway next to Lemma. You only do this once.
