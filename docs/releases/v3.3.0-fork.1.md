This fork's release based on [Lemma 3.3.0](https://github.com/fus3r/lemma/releases/tag/v3.3.0), which includes the reading changes and the Dock fix of v3.2.1-fork.1.

## Changes from Lemma 3.3.0

- **Windows.** Lemma can have several windows, each with its own tabs, panels and layout (File › New Window, ⇧⌘N). A new window takes the side bars, panel and sizes of the window it comes from. Drag a book's tab out of its window to open it in a new window there, onto another window's tabs or page to move it into that window, or choose Move Tab to New Window from the tab's menu. A book is open in one window at a time: opening it from another window brings its window to the front. Tabs can now be dragged to the right along the tab bar too.
- **Updates.** Lemma no longer installs updates of the original app over this one. Check for Updates… reports new releases of this fork.

## Install

Download `Lemma-3.3.0-fork.1.dmg` below, open it and drag Lemma into Applications. It runs on macOS 15 or later, on Apple silicon and Intel. It replaces the original Lemma if you have it, and keeps your library and settings; coming from the original Lemma, the tabs you had open are not reopened the first time.

This build is not notarized by Apple, so the first time you open it macOS says it cannot verify it. Click Done, then open System Settings › Privacy & Security and click Open Anyway next to Lemma. You only do this once.
